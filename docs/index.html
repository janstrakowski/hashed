HashedBuild

A build-system language, in progress

A files-as-values, context-threaded language with opt-in concurrency, capability-style permissions, and a genuinely pausable/resumable interactive debugger.

Language spec The full draft: program model, types, functions, control flow, async, filesystem builtins. Debugger playback Every example, stepped through the live editor's pausable debugger and captured frame by frame.
